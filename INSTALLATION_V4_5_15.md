# Installation — IARS V4.5.15

Replace the complete files from this package in the current IARS repository, especially:

1. `app.py`
2. `iars_excel_conversion.py`
3. `assets/invoice_conversion_template.xlsx`
4. Existing supporting files and assets included in the package

Commit and push the files to the deployed branch, wait for Streamlit Cloud to finish redeploying, then hard-refresh the browser with `Ctrl + F5`.

Expected displayed version: `v4.5.15`.
