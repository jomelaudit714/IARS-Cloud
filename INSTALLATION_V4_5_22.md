# Installation — IARS V4.5.22

1. Extract the ZIP.
2. Upload the extracted contents directly to the root of the GitHub repository.
3. Replace the existing `app.py`, `iars_gantt.py`, and `assets/gantt_master_data_template.xlsx` files.
4. Reboot the Streamlit application.
5. Confirm that the system displays version `4.5.22`.

No new Supabase SQL migration is required for this UI and formatting update.
