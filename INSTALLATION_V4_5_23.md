# Installation — IARS V4.5.23

1. Extract the ZIP.
2. Upload the extracted contents directly to the root of the GitHub repository.
3. Replace the existing `app.py` and `iars_gantt.py` files and keep the existing assets.
4. Reboot the Streamlit app.
5. Confirm that the system header displays version `4.5.23`.
6. No Supabase SQL migration is required for this layout-only update.
