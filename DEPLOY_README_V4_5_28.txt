IARS V4.5.28 CLEAN FULL DEPLOYMENT

This package contains only the runtime-essential IARS files, required assets,
Streamlit configuration, dependency files, and Supabase setup/migration SQL files.
Historical changelogs, test outputs, previews, duplicate images, and old installers
were intentionally removed to stay below the GitHub web upload limit.

IMPORTANT DEPLOYMENT STEPS
1. Extract this ZIP on your computer.
2. Open the extracted folder.
3. Upload ALL extracted files and folders to the ROOT of the GitHub repository.
   Do not upload the ZIP itself and do not place the files inside another folder.
4. Choose Replace/Overwrite for existing files.
5. Reboot the Streamlit app.
6. Confirm the system header shows v4.5.28.

Do not upload a real secrets.toml file to GitHub. Configure secrets only through
Streamlit Community Cloud > App settings > Secrets.
