# Installation

Copy these files into the current IARS repository:

1. `app.py`
2. `iars_excel_conversion.py`
3. `assets/warehouse_conversion_template.xlsx`

The package also carries forward the approved V4.5.10 `iars_auth.py`, `iars_theme.py`, and approved image assets.

After pushing to the deployment branch, wait for Streamlit Cloud to complete the rebuild, then perform a hard refresh (`Ctrl + F5`).

Expected visible version: `4.5.11`.
