# Installation

Replace these files in the current branch/repository:

1. `app.py`
2. `iars_auth.py`
3. `iars_theme.py`
4. Entire `assets` folder from this patch

Then commit and push the branch. Wait for Streamlit Cloud to finish redeploying, then hard-refresh the browser with `Ctrl + F5`.

Expected displayed version: `v4.5.08`.
