# IARS V4.4.98 Changelog

## Policies & Memoranda table

- Rebuilt each document entry as a keyed row with one calculated shared minimum height.
- When the Title, Subject / Process, or another text value wraps, every cell in the same row expands to the same height.
- Prevented long titles from crossing or extending below the Title border.
- Kept the complete row border continuous from Title through Download.
- Applied bold font only to document titles.
- Applied normal font weight to Type, Subject / Process, Version, Effective Date, Uploaded By, View, and Download.
- Preserved search, folder rename, preview, download, edit, delete, and successful-upload field reset behavior.
