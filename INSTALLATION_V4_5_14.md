# Installation — IARS V4.5.14

Replace/copy the full package contents into the current project. At minimum, make sure these files are included:

1. `app.py`
2. `iars_excel_conversion.py`
3. `assets/invoice_conversion_template.xlsx`

The package also includes the existing Warehouse and LOGP assets. Commit/push the files to the deployment branch, wait for Streamlit Cloud to complete redeployment, and hard-refresh the browser with `Ctrl + F5`.

Expected displayed version: `v4.5.14`.
