# Installation

Use the V4.5.13 folder contents to replace the corresponding files in the full IARS repository.

Required files:

1. `app.py`
2. `iars_excel_conversion.py`
3. `iars_auth.py`
4. `iars_theme.py`
5. `assets/logp_conversion_template.xlsx`
6. Existing assets included in the package

Commit and push to the deployment branch, wait for Streamlit Cloud to finish redeploying, then hard-refresh the browser using `Ctrl + F5`.

Expected header version: `v4.5.13`.
